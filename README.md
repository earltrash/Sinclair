# Sinclair
2Q_Project
DirectX 1 기반의 UI 중심 성장/진행형 게임입니다.  
튜토리얼에서 클릭으로 규칙을 학습한 뒤, 아이템을 지급받아 스탯 상승 → 강화/합성 → 멀티 엔딩을 목표로 진행합니다.

- 장르: UI 기반 성장/시스템 중심 게임
- 핵심: 인벤토리 / 강화 / 아이템 합성 / 튜토리얼 / 멀티 엔딩
- 엔딩 구조: Sinclair 1세 → 2세 → 3세 진행 후 엔딩 확인, 결과 화면에서 지금까지 본 엔딩이 순차적으로 표시

## 게임 진행(플로우)
1. 튜토리얼 씬: 클릭을 통해 시스템 설명
2. 아이템 지급
3. 인벤토리에서 아이템 사용/강화/합성
4. 스탯이 충분히 상승하면 조건에 따라 엔딩 분기
5. Sinclair 1~3세(총 3회 플레이) 진행 후
6. 결과 화면: 지금까지 본 엔딩 목록(순차 표시) → 종료

## 주요 시스템
- 인벤토리
  - 아이템 획득/보관/사용
- 강화 시스템
  - 강화로 스탯 상승(성장 핵심 루트)
- 아이템 합성
  - 재료 조합으로 상위 아이템 생성
- 튜토리얼(클릭 기반 가이드)
  - UI 조작/시스템 이해를 단계적으로 안내
- 멀티 엔딩 + 엔딩 기록
  - 엔딩 분기, 결과 화면에서 누적 엔딩 표시
